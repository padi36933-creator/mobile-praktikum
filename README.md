# Proyek Pemrograman Mobile

## Deskripsi & Tujuan
Aplikasi latihan untuk pengembangan mobile berbasis Flutter, bertujuan memberikan solusi kemudahan layanan on-demand.

## Pengembang
Nama panggilan / akun GitHub: padi36933-creator

## Rencana Fitur
1. **Pemesanan Layanan:** Memungkinkan pengguna memesan transportasi atau layanan harian secara langsung.
2. **Riwayat Transaksi:** Menampilkan catatan pesanan yang telah dilakukan pengguna.
3. **Profil & Pengaturan:** Pengaturan akun pengguna dan informasi aplikasi.
